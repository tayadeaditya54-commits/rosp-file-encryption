MINI PROJECT • PROBLEM IDENTIFICATION

6. Experiment 10: Mini Project Problem Statement

UNTITLEDUICO/REACT
Target: Untitled UI React (untitleduico/react)
In InputBase, the eye toggle button is positioned absolutely at the trailing edge. However, trailing padding calculations only checked tooltips and validation error states, completely omitting password fields.

Impact: Long passwords visually collide with and slide beneath the eye toggle button, violating UI clarity and user privacy checks.
Associated Accessibility (WCAG) Deficiencies
  • ✕ Clickable while disabled: Toggle remained clickable when input was disabled.
  • ✕ Missing ARIA label: Lacked dynamic voiceover announcements for screen readers.
  • ✕ Unintended submit: Lacked explicit type="button" attribute.
  • ✕ Type pollution: InputNumber imported copy-pasted date types.
