## 📌 Project Overview

This repository contains the implementation, automated test suite, technical report, and presentation deck for Experiment 10 (Mini Project) of the ROSP curriculum.

The project provides an open-source, high-performance, and mathematically proven **Authenticated File Encryption & Decryption System** implementing **AES-256 in Counter (CTR) Mode** coupled with **HMAC-SHA256 (Encrypt-then-MAC)**.

### ✨ Key Features

* **Authenticated Encryption (AEAD):** Uses Encrypt-then-MAC architecture to guarantee both confidentiality and cryptographic integrity.
* **NIST FIPS-197 Compliant AES-256 Engine:** Zero external native dependencies; executes cleanly across Windows, Linux, and macOS without DLL permission issues.
* **PBKDF2-HMAC-SHA256 Key Derivation:** Derives independent 256-bit encryption and authentication keys using 600,000 iterations and a 128-bit cryptographically secure random salt.
* **$O(1)$ Constant Memory Streaming:** Streams large files in 64 KB buffers, allowing multi-gigabyte databases, videos, and archives to be encrypted without memory exhaustion.
* **Strict Tamper Detection:** Even a single-bit alteration in the encrypted header or ciphertext payload immediately aborts decryption with an `IntegrityError`.
* **Zero Plaintext Leakage:** Complete cryptographic verification is enforced before any plaintext bytes are written to disk.

## 🛠️ Binary Header Format

Every encrypted file (`.enc`) generated by this tool uses the following structure:

```text
+------------------+------------------+------------------+-----------------------+-------------------+
| Magic (8 Bytes)  | Salt (16 Bytes)  | IV (16 Bytes)    | Ciphertext (Variable) | HMAC Tag (32 Bytes)|
| b"ROSPENC1"      | secrets.token    | secrets.token    | AES-256-CTR Stream    | SHA-256 HMAC      |
+------------------+------------------+------------------+-----------------------+-------------------+
|<------------------------- Authenticated by HMAC-SHA256 Tag ------------------------->|
```

## 🚀 Quick Start Guide

### 1. Requirements
* Python 3.9+ (No third-party packages required — zero external dependencies!)

### 2. File Encryption
```bash
python file_encryptor.py encrypt confidential.pdf -p "MyStrongPassword#2026"
# Outputs: confidential.pdf.enc
```

### 3. File Decryption
```bash
python file_encryptor.py decrypt confidential.pdf.enc -p "MyStrongPassword#2026"
# Restores: confidential.pdf
```

### 4. Integrity Verification (Dry-run)
```bash
python file_encryptor.py verify confidential.pdf.enc -p "MyStrongPassword#2026"
# Validates header, salt, and HMAC-SHA256 tag without modifying disk files
```
