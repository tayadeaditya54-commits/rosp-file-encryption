Experiment 10: File Encryption Details (Your Contribution)

  • Target Domain: Open Source File Security & Cryptography
  • Identified Problem: Memory exhaustion during large file encryption and missing authenticated encryption (AEAD) leading to bit-flipping vulnerabilities
  • Code Implementation: NIST FIPS-197 AES-256 CTR Mode stream cipher with 64 KB chunked streaming for constant O(1) memory overhead
  • Security & Integrity: PBKDF2-HMAC-SHA256 key derivation with 600,000 iterations + 128-bit salt; Encrypt-then-MAC using HMAC-SHA256 for instant tamper detection
  • GitHub Repository: https://github.com/adityatayade/rosp-file-encryption
